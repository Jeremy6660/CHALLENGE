# CareMind 系统架构图（Mermaid + 文本版）

## 1. 分层架构图（Mermaid 格式 — 可复制到 Mermaid Live Editor 渲染为PNG）

```mermaid
graph TB
    subgraph INPUT[输入层]
        A[老人全维档案<br/>诊断·用药·ADL·量表·社会史]
    end

    subgraph ASSESS[评估层 — 4 Agent 并行]
        B1[🏥 医疗评估Agent<br/>慢病管理·用药安全·急性风险]
        B2[💉 护理评估Agent<br/>ADL·跌倒·压疮·照护等级]
        B3[🤝 社工评估Agent<br/>心理·社交·家属·认知]
        B4[🍽️ 餐饮评估Agent<br/>营养·吞咽·膳食方案]
    end

    subgraph ORCH[编排层]
        C[🧠 Orchestrator Agent<br/>冲突消解·优先级排序·统一计划]
    end

    subgraph DECIDE[决策审核层]
        D[⚖️ Decision Agent<br/>合理性·安全性·可行性三审]
    end

    subgraph OUTPUT[输出层]
        E1[📋 综合干预计划<br/>紧急/本周内/持续]
        E2[⚠️ 风险预警清单]
        E3[💬 家属沟通报告]
    end

    A --> B1
    A --> B2
    A --> B3
    A --> B4
    B1 --> C
    B2 --> C
    B3 --> C
    B4 --> C
    C --> D
    D --> E1
    D --> E2
    D --> E3

    style INPUT fill:#e3f2fd
    style ASSESS fill:#fff3e0
    style ORCH fill:#f3e5f5
    style DECIDE fill:#e8f5e9
    style OUTPUT fill:#fce4ec
```

## 2. Agent数据流图

```mermaid
sequenceDiagram
    participant User as 👤 用户/系统
    participant CB as 📦 Context Builder
    participant M as 🏥 医疗Agent
    participant N as 💉 护理Agent
    participant S as 🤝 社工Agent
    participant D as 🍽️ 餐饮Agent
    participant O as 🧠 Orchestrator
    participant DC as ⚖️ Decision Agent

    User->>CB: 请求评估(elderly_id)
    CB->>CB: 组装全维档案

    par 并行评估
        CB->>M: 医疗数据
        M-->>O: 医疗评估报告
        CB->>N: 护理数据
        N-->>O: 护理评估报告
        CB->>S: 社工数据
        S-->>O: 社工评估报告
        CB->>D: 餐饮数据
        D-->>O: 餐饮评估报告
    end

    O->>O: 规则引擎冲突消解
    O->>O: LLM深度编排
    O->>DC: 统一干预计划草案

    DC->>DC: 合理性审核
    DC->>DC: 安全性审核
    DC->>DC: 可行性审核
    DC-->>User: PASS + 最终计划 + 执行摘要
```

## 3. 冲突消解流程图

```mermaid
graph LR
    subgraph 冲突检测
        R1[规则1: 活动限制 vs 社交需求]
        R2[规则2: 饮食限制 vs 疾病指征]
        R3[规则3: 探视需求 vs 感染风险]
        R4[规则4: 吞咽困难 vs 营养目标]
    end

    subgraph 消解策略
        S1[safety_first<br/>安全优先]
        S2[medical_first<br/>医疗优先]
        S3[compromise<br/>折中方案]
    end

    subgraph 输出
        O1[替代活动方案]
        O2[疾病适应饮食]
        O3[视频探视+预约制]
        O4[鼻饲方案统一]
    end

    R1 --> S1 --> O1
    R2 --> S2 --> O2
    R3 --> S3 --> O3
    R4 --> S1 --> O4
```
